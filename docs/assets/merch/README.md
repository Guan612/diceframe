字体沿用产品字体栈：标题 `Palatino Linotype / Iowan Old Style / Palatino / Georgia`，正文 `Aptos / Segoe UI`，等宽 `Consolas`。

几何来源：骰子不是随手画的图标，而是把正二十面体、正十二面体、正八面体、正四面体、立方体真实投影后做隐线消除得到的线稿（见各文件中 d20/d12/d8/d4/d6 路径）。品牌中心字形沿用 `docs/assets/diceframe-logo.svg` 的「框 + 骰面」结构。

## 出片前

1. **文字转曲**。文件里的文字仍是可编辑文本，字体依赖本机。Illustrator: 选中文本 → 创建轮廓；Inkscape: 路径 → 对象转路径。转曲后再送印，避免字体替换导致弧排文字错位。
2. **单色件**。`02` 是纯 `#101820` 描边，替换颜色即可（整份文件只有一个 ink 值）。
3. **透明底**。`02`、`06`、`10` 没有底色：印深色布料直接用，印浅色布料要先反色（把金 `#c7a362` 换成墨色 `#101820`）。
4. **安全区**。模切贴纸建议按最外轮廓外扩 2mm 出血；`01`/`03`/`04`/`08` 的圆形/星形轮廓可直接作为刀模线。
5. **尺寸**。线稿在 3cm 以下会糊，贴纸建议 ≥ 5cm，海报按画布等比放大即可（纯矢量）。

## 二次修改

- 换配色：全局替换 6 个色值即可。
- 换文案：`03`/`04`/`05`/`07` 的文案是独立 `<text>`，注意弧排文字（`01`）的 `startOffset` 是按当前字号和字距算好的；改字号或字距后需要重新居中对齐。

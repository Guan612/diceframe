# 📋 DiceFrame Quick Guide

## 📖 Website and documentation

Open Settings → About to visit the [DiceFrame website](https://diceframe.com), [GitHub project](https://github.com/diceframe/diceframe), and documentation.

## 🛟 When something goes wrong

Use the Logs page for in-game generation and processing records. For startup, network, or Docker failures, also inspect the terminal or container logs.

When reporting a problem, include the DiceFrame version, deployment method, reproduction steps, and sanitized errors in [GitHub Issues](https://github.com/diceframe/diceframe/issues). **Never post API keys, passwords, tokens, private chats, or full saves.**

## ⚠️ Feedback

DiceFrame is maintained by open-source contributors. Reports are handled according to reproducibility, security impact, project direction, and available maintenance capacity. Public Issues are not suitable for secrets or private data.

## 💡 Contribute

Contributions, documentation improvements, and reviews are welcome under [AGPL-3.0](https://github.com/diceframe/diceframe/blob/main/LICENSE).

## 📄 Terms and privacy

Before continuing, read the complete [Terms of Use](/#/legal/terms) and [Privacy Policy](/#/legal/privacy). Anonymous usage statistics are off by default and begin only after active opt-in; keeping them off does not restrict local features.

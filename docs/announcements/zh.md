# 📋 DiceFrame 使用指引

## 📖 官网与文档

您可以在“设置 → 关于”打开 [DiceFrame 官网](https://diceframe.com)、[GitHub 项目](https://github.com/diceframe/diceframe)和使用文档。

## 🛟 遇到问题时

游戏内的生成与处理记录可在“日志”页面查看；程序启动、网络和 Docker 问题请同时查看启动终端或容器日志。

提交反馈时，请写明 DiceFrame 版本、运行方式、复现步骤和已经脱敏的错误信息，并通过 [GitHub Issues](https://github.com/diceframe/diceframe/issues) 提交。**请勿上传 API Key、访问密码、Token、私人聊天或完整存档。**

## ⚠️ 反馈说明

DiceFrame 是由贡献者共同维护的开源项目。维护者会根据可复现性、安全影响、项目方向和维护资源处理反馈；公开 Issue 不适合提交隐私或安全凭证。

## 💡 参与开源

欢迎依据 [AGPL-3.0](https://github.com/diceframe/diceframe/blob/main/LICENSE) 在 GitHub 提交 Pull Request、改进文档或参与代码审查。

## 📄 用户协议与隐私

继续使用前，请阅读完整的 [用户协议](/#/legal/terms) 和 [隐私政策](/#/legal/privacy)。匿名使用统计默认关闭，只有您主动开启并确认后才会发送；不启用不影响本地功能。

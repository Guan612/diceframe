# DiceFrame v1.9.9

## 中文

这个版本把 QQ / NapCat 插件重新改为内置，开箱即用，无需再去插件商店下载；同时修复了部分旧版本升级时用户插件没有自动迁移的问题。

### 新功能

- QQ / NapCat 插件重新内置：安装主程序即可使用，无需从插件商店单独下载。

### 修复

- 修复从 1.9.5 及更早的旧布局便携版升级时，已安装的用户插件没有自动迁移到数据目录的问题。

### 下载指南

- **普通 Windows 用户**：下载 `DiceFrame-v1.9.9-windows-portable.zip`。
- **源码运行用户**：下载 `DiceFrame-v1.9.9-windows.zip`。
- `.sha256` 是更新校验文件，普通用户不需要手动下载。

## English

This release makes the QQ / NapCat plugin built-in again so it works out of the box without a separate install from the plugin store, and fixes a migration issue where user-installed plugins were not carried over when upgrading from older portable builds.

### New Features

- The QQ / NapCat plugin is built in again: it works right after installing DiceFrame, no separate download from the plugin store needed.

### Fixes

- Fixed user-installed plugins not migrating to the data directory when upgrading from 1.9.5 and earlier portable builds with the legacy layout.

### Download Guide

- **Regular Windows users**: download `DiceFrame-v1.9.9-windows-portable.zip`.
- **Source-run users**: download `DiceFrame-v1.9.9-windows.zip`.
- `.sha256` files are update checksums; regular users do not need to download them manually.
